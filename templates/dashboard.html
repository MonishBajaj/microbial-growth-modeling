      Temperature source

      Where the time–temperature profile comes from. Sample data needs no device.

      Upload arduino/temperature_push/temperature_push.ino with this URL and token. The board must reach this host over the internet (tunnel or deployed server).

      Refresh opens App Check. If automatic mint fails, the popup asks you to paste a capture script in the ThermoWorks Console (opening ThermoWorks alone is not enough).

      Close the Arduino Serial Monitor before starting. Sketch prints one Celsius value per line at 9600 baud.

      Boards appear automatically when they announce themselves. Type an address if needed.
