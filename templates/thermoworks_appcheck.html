Install the Chrome helper once (required for automatic server handoff). Without it, the browser will not let this site read ThermoWorks’ captcha.

  1. Open chrome://extensions
  2. Enable Developer mode
  3. Load unpacked → folder chrome_extension/thermoworks_appcheck from the repo
  4. Come back here and click Refresh on the dashboard again

Use the same Chrome where you installed the helper (not another browser).
