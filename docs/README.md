# Documentation in this folder

[USER_GUIDE.md](USER_GUIDE.md) is the walkthrough: sign-in, the four run modes, and the exact request each temperature source sends.

[ARDUINO_SETUP.md](ARDUINO_SETUP.md) is the hardware guide: downloads, DS18B20 wiring, which port is which, and both sketches to paste into the Arduino IDE.

[CONNECT_THERMOMETERS.md](CONNECT_THERMOMETERS.md) is how to attach a MEATER account, a ThermoWorks Signals device, and the Chrome App Check extension.

[FILES.md](FILES.md) is the index of every project file and what it is responsible for.

The project [README](../README.md) is the short entry point. Comments at the top of the Python, HTML, CSS, JavaScript, and Arduino files repeat the same roles for someone who opens a single file first.
